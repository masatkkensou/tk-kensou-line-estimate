# TK建装 LINEかんたん見積 Ver.1

一般個人向け住宅・マンションの表層リフォームの概算を表示する、スマートフォン向け静的Webアプリです。7段階で部屋・施工範囲・クロス・イメージ・家具・追加工事を選び、税込概算と内訳を表示します。

## ローカルで起動

依存パッケージのインストールやビルドは不要です。リポジトリ直下で実行します。

```sh
python3 -m http.server 8000
```

ブラウザーでポート8000にアクセスします。`index.html`を直接開いても動作します。

## GitHub Pages

GitHubリポジトリの **Settings → Pages → Build and deployment → Deploy from a branch** で、ファイルを反映したブランチの `/ (root)` を指定します。ファイルは相対パス参照のため、リポジトリ名を含むPagesのURLでも動作します。公開操作は別途必要です。

## 料金の変更

**`pricing.js` の `window.ESTIMATE_PRICING` が唯一の料金設定です。すべて税抜・円単位の仮価格です。**

| 設定 | 用途 |
| --- | --- |
| `rooms` | 6・8・10・12畳の `walls`（壁料金）、`ceilingAddition`（天井追加料金）、`floor`（床張替え料金） |
| `wallpaperMultipliers` | STANDARD・SELECTのクロス工事料金倍率 |
| `furniture` | 家具移動の一式料金 |
| `options` | 巾木・プレート・照明・カーテンレールの一式料金 |
| `taxRate` | 消費税率（0.10 = 10%） |

計算：クロス料金 =（壁料金 ＋ 壁＋天井を選んだ場合の天井追加料金）× クロス倍率（円単位で四捨五入）。家具移動と選択オプションを加算した税抜小計に、消費税（円単位で四捨五入）を加えます。イメージ選択による追加料金はありません。床料金は部屋の広さに連動し、その他のオプションは1部屋あたりの仮の一式料金です。

初期設定の例：6畳 → 壁＋天井 → STANDARD → 明るい白 → 家具なし → オプションなし = 税抜48,000円 ＋ 消費税4,800円 = **税込52,800円**。

正式価格は現地確認後に確定します。数量・下地・材料などの詳細な条件はVer.1の概算対象外です。

## ファイル構成

- `index.html`：UTF-8の画面構造・デモダイアログ
- `style.css`：スマートフォン優先のレスポンシブデザイン
- `pricing.js`：料金設定
- `app.js`：ウィザード・選択状態・概算計算
- `tests/smoke.cjs`：Playwrightによる操作テスト

LINE API・LIFF・写真送信・顧客情報保存・外部サービス連携はありません。入力はメモリ内のみで保持し、再読み込みすると消えます。「写真を送って無料見積」は説明ダイアログを開くデモです。外部フォント・ライブラリー・分析サービスの読み込みもありません。

## 動作確認

開発用テストにはPlaywrightとChromiumが必要です（アプリの実行には不要）。別ターミナルで上記の静的サーバーを起動後、実行します。

```sh
node tests/smoke.cjs
# システムのChromiumを利用する場合
CHROMIUM_PATH=/usr/bin/chromium node tests/smoke.cjs
```

Playwrightがない開発環境では、`npm install --no-save --package-lock=false playwright` と `npx playwright install chromium` で準備できます。テスト対象URLは `TEST_URL` で変更可能です。

テスト対象：指定の6畳の一連操作、戻る際の選択保持、オプション複数選択、料金設定の変更反映、12畳・SELECT・全オプションの計算、デモダイアログ、やり直し、320/390/768/1280px幅での横はみ出し、JavaScriptエラー。
