# TK建装 LINEかんたん見積（原価積み上げ方式）

スマートフォン向けの概算見積デモ。LINE API・LIFF接続や写真送信は未実装です。

## 基本料金（税抜）
- 部屋：6/8/10/12畳。複数部屋は追加選択（同じ畳数の追加は現地見積で調整）
- 壁面積：6畳29.9、8畳34.6、10畳38.6、12畳42.3㎡
- 壁＋天井面積：6畳39.6、8畳47.6、10畳54.8、12畳61.7㎡
- クロス材料原価：普及品380円/㎡・一般品670円/㎡
- 剥がし＋張り労務原価：800円/㎡（2人合計）
- 施工能力：2人で60㎡/日、端数切り上げで日数計算
- 交通諸経費：5,000円/日
- 現場管理費：材料＋労務＋交通の10%
- 売価：総原価÷0.70を1,000円単位に切り上げ（目標粗利30%以上）
- 産廃処分費は今回の原価計算に含めないため、実負担があると実際の粗利益率は下がります。
- 消費税：10%

例：6畳・壁＋天井・普及品・家具なし・追加工事なしは税抜82,000円、税込90,200円。
12畳・壁＋天井・普及品は61.7㎡で2日施工、税抜131,000円。
6畳＋8畳・壁＋天井・普及品は87.2㎡で2日施工、税抜178,000円。

## 追加料金（従来の仮設定）
家具移動：小型2,000円、大型1点2,000円、大型2点以上4,000円。
床張替え・巾木・プレート・照明・カーテンレールは旧来の仮価格。追加項目の粗利30%は保証されません。追加部屋の床工事は部屋別床価格を合算します。

## 施工保証案内
当社施工に起因する不具合について、引渡しから1年の施工保証を想定。
具体的な対象・除外事項・受付方法・補修範囲は契約前に書面で定める必要があります。
法定の契約不適合責任を一律に制限する趣旨ではありません。

## 公開方法
GitHub Pagesでmainブランチのルートを公開。index.html/style.css/pricing.js/app.jsの静的構成。
表示金額は目安です。実際の施工日数・実測面積・下地状態によって正式見積を確定します。
